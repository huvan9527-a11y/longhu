# 龙虎榜双模拟仓

两个账户各20万元：`original` 原方案；`reentry` 原方案加止损后重新入场。2026-10-08开始向前模拟，不将历史回测收益带入账户。

每个工作日北京时间 **17:10、19:10、21:10执行，每两小时复查一次**。GitHub可能延迟调度。当天选股使用龙虎榜披露中的收盘价与当日涨幅，不依赖通达信日线包；每次重新抓取全部榜单和席位，检查每个独立披露的买卖席位数量，再间隔15秒抓取核对稳定性。早期结果属于初筛，不能保证全市场已经完成发布。数据不齐则报告“等待披露”，任务报错，不把缺失当作无信号。

**选股与账本分开更新**：选股见 [当日选股](reports/latest_signals.md)、[当前信号](reports/current_signals.csv)、[检查状态](reports/screening_status.json)；模拟账本20点后才尝试获取完整日线包。提前手动运行也会筛选当天，账本明确标注等待晚间行情。历史行情与披露按日冻结，同日补跑不重复下单；当天已冻结披露若发生变化，阻止账本更新并报错，等待核对，避免悄悄漏信号或改写旧净值。休市期间不生成交易。

查看 [最新报告](reports/latest.md)、[原方案账本](reports/original)、[重新入场账本](reports/reentry)、[Actions](../../actions)。各账户导出逐笔交易、每日资产、成交/未成交记录、事件及下一交易日开盘计划。

## 选股

仅0、6开头股票。T日收盘较昨收上涨至少5%；任意同日披露卖出席位存在“机构专用”即排除。

- 0开头：买入席位中至少一条机构专用记录自身买入额严格大于2000万元、自身卖出额等于0。不将多个席位凑足2000万元。
- 6开头：同一独立披露中机构专用买入席位的买入额合计严格大于2000万元，不检查该买入席位的卖出额。
- 单日、连续多日披露均纳入；不同披露独立判定、不跨原因累加；同股票同日只生成一条信号。无法辨认的重复机构记录跳过。

## 交易

下一交易日开盘尝试买入，每笔含费投入不超过下单前总资产1/3，遵守板块数量限制，不补仓。开盘涨跌停、停牌记未成交。费率单边万分之1.5（往返约万分之3），沿用历史方案单边0.1%不利滑点。

**2026-10-26起，两个账户统一买入后的下一交易日收盘全仓卖出。**例如周一开盘买，周二收盘卖；周五开盘买，下周一收盘卖。停牌或收盘跌停无法成交时，后续交易日收盘继续尝试。

新规则不再执行盘中10%止损、+5%半仓止盈、保本止损或持有10天退出，也不再生成止损后的重新入场信号。原`reentry`账户保留原有现金、持仓和历史记录，生效后与`original`使用相同的退出规则，仍各自独立记账。

生效日前历史沿用旧规则，不重写成交和净值。生效日的存量持仓（如航天南湖、乐鑫科技）统一在该日收盘尝试退出，不能补记为过去已卖出。生效日期固定在`config.json.next_day_exit_from`，确保全历史重放与旧账本校验兼容。

## 模拟口径

这是盘后日线模拟，不连接券商、不发送真实委托。当天开盘买入与到期收盘退出，在晚间取得完整行情后记账。保留原费用及单边0.1%不利滑点；日线模拟无法验证真实盘口成交。

行情：通达信官方每日行情包（未复权），日历辅助：腾讯上证指数日线；龙虎榜：东方财富每日披露与买卖席位明细，保留原始数据。历史收盘/除权参考价构建因果价格基准用于指标。若持仓遇到除权除息，自动停止本次账本更新并报错，需核验真实转增股数、现金分红后扩展账本处理；不会把价格调整系数当作真实股数。

首次自动运行会初始化账户。手动补跑在 Actions 的 Run workflow；重新执行使用冻结数据重算，并核对旧净值不被改写。运行失败保留上一次账本，在Actions查看错误。不要删除data或修改start_date以免重置账户。

本地：`pip install -r requirements.txt`，`python -m unittest discover -s tests -v`，先 `python preview.py` 筛选当日，再 `python run.py` 更新晚间账本。
